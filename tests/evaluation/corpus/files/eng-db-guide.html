Database operations guide

The primary PostgreSQL cluster is backed up every night at 02:30 UTC. Backups are kept for 35 days.

Point-in-time recovery

Write-ahead logs are archived continuously, so the database can be restored to any second within the last 7 days. A restore drill is run once per quarter.

Migrations

Schema migrations must be backwards compatible with the previous release. Destructive migrations need two releases: first stop using the column, then drop it.

Connection limits

Each service may open at most 20 connections to the primary cluster.
