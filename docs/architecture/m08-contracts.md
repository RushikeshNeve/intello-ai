# M08 contracts: security, operations, CI and baseline (slim, lean mode)

Frozen 2026-11-20. **Not a release**: nothing is deployed or published; the end result is a git baseline tag + checklist. Lean tests; deeper versions live in `docs/execution/TEST_DEBT.md` for the testing pass after M09. The repo is public: CI uses only free GitHub Actions, no secrets.

## M08.01 Security (agent A) — `tests/security/**`, no app behaviour changes unless a real defect is found (then minimal fix + test + note)
- **01.01 Tenant/grant adversarial (route sweep):** an automated sweep over the live OpenAPI schema: for EVERY route with `{org_id}` / `{workspace_id}` path params, (a) unauthenticated → 401, (b) a user from another org → 404 (concealed) never 200/403 leaking existence, (c) org member without workspace access → 404, (d) viewer on a write route → 403. Per-route fixtures generated from a registry (skip list with reasons for routes that cannot be generically exercised). Also resource-grant check (document grant opens one doc only, never search/graph/counts) and count-leak check (list/search/graph counts never include unauthorized items).
- **01.02 Prompt injection and tool permissions:** run the evaluation injection items + a new hostile-document set through the REAL prompt/verification path with scripted obedient models: no policy/provider change, no cross-tenant evidence, no system-prompt leak, no instruction-bearing text outside the system message; graph extraction and memory/research prompts get the same fenced evidence; assert there is no tool/function-calling surface reachable from retrieved text (inventory test of gateway capabilities).
- **01.03 Deletion lineage + cache invalidation:** after deleting a document everything denies: search, evidence chunk, citations in old chat messages, graph neighborhood/claims, memories (invalidated), research report citations re-resolved, artifacts removed, RushDB records gone (searches + raw query), and any in-process caches (rate limiter, graph repo cache, policy cache) hold no deleted content. Integration test on real Postgres (+ in-memory index) and a checklist of the live check.
- **01.04 Credential rotation / connector revoke:** `CONNECTOR_ENCRYPTION_KEY` rotation via `CONNECTOR_ENCRYPTION_OLD_KEYS` (old tokens still decrypt, re-encrypt on use or via a rotation command, new key id recorded), webhook secret rotation, revoke wipes ciphertext and blocks access, no token/secret in logs/audit/API responses/traces (sweep logs with canary secrets).

## M08.02 Operations (agent B)
- **02.01 Backup automation:** `scripts/ops/backup.sh` (+ PowerShell wrapper): consistent PostgreSQL dump (all schemas, roles-free), RushDB cold snapshot (stop-copy-start or documented consistent method), object-store export (buckets: originals, artifacts), `.env` NOT included, a manifest with sha256 checksums and versions (migration head, embedding space id, pipeline version), retention option, restore-compatibility note. Tests: run against an isolated compose project.
- **02.02 Restore rehearsal:** `scripts/ops/restore.sh` into a fresh project; automated verification: row counts per table, object checksums, RushDB record counts per tenant, text/vector indexes recreated (known RushDB condition: text indexes re-created after restore), a search + citation + graph query works, migration head matches. Extend/replace `scripts/restore_smoke.sh`.
- **02.03 Load and fault injection:** `tests/load/` Node scripts (no new deps): N concurrent searches, chat runs (scripted stub model), a burst of uploads; record p50/p95/p99 + error rate + worker queue drain; fault cases already covered by the M03 gate are referenced, add: Redis restart, Postgres restart, embedder down. Results written to `docs/ops/load-results.md` with the machine description; no pass/fail thresholds beyond "no data loss/duplicates".
- **02.04 Tracing and dashboards:** correlation id (`X-Request-Id`, W3C `traceparent`) propagated API → outbox payload → Celery headers → worker → embedding/chat calls; structured JSON logs with `trace_id`/`request_id`/`org_id`(hash)/`job_id`; OpenTelemetry SDK (add only the needed `opentelemetry-*` packages) exporting OTLP to an optional compose profile `observability` (otel-collector + Jaeger + Prometheus + Grafana with a provisioned dashboard: request latency, queue depth, ingestion/chat/research run durations, error rates); `/metrics` (Prometheus) bound to the internal network only, never publishing text/ids of content. Disabled by default (`OTEL_ENABLED=false`).

## M08.03 Quality, docs, baseline (agent C)
- **03.01 CI gates:** `.github/workflows/ci.yml` (free runners, no secrets): API lint (ruff), strict mypy, unit tests, DB/RLS integration suites with Postgres/Redis service containers (the suites that run without Docker-in-Docker; document the ones that need compose and run them in a separate manual/nightly workflow), web lint/typecheck/test/build, dependency audit (`pip-audit`, `npm audit --omit=dev` non-blocking report + blocking on critical), the evaluation gate (`tests/evaluation/run_eval.py --require-baseline`), OpenAPI contract snapshot check (fail on unreviewed route/schema changes; snapshot file committed, update command documented), `docker compose config` validation, secret scan (gitleaks or a small regex job), branch-protection recommendation doc. Cache pip/npm. Must pass on a clean checkout locally (act not required; reproduce the commands in `scripts/ci/run_local.sh`).
- **03.02 Runbooks:** `docs/runbooks/{install.md (clean machine: Windows+Docker+LM Studio, all steps, versions), operations.md, security-incident.md (credential leak, tenant isolation breach suspicion, connector compromise, deletion requests), backup-restore.md, troubleshooting.md}`; every command tested or marked untested.
- **03.03 Acceptance + checklist:** `docs/release/CHECKLIST.md` listing every P0 gate with evidence pointers (commands + latest results); an acceptance runner `tests/e2e/acceptance/run.sh` booting a full stack in its own compose project with stub embedding + scripted chat stub (no LM Studio needed) and running the essential flows (sign-in → upload → ready → search → chat grounded → graph → memory → research → connector fixture → deletion → backup/restore smoke if cheap); reuse `tests/e2e/fullstack_m03` helpers.
- **03.04 Baseline tag:** annotated git tag `baseline-m08` (local; pushed only with the milestone push) + `docs/release/BASELINE.md`: versions, migration head, embedding space, known deferrals (TEST_DEBT, POST_M09_BACKLOG, M09/M10 scope), unsupported features list. **No GitHub Release, no deployment.**
