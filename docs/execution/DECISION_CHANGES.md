| DC-009 | 2026-11-16 | Gate verdict | **RushDB CONDITIONAL GO** for ADR-012/014 (M00.03.01–03; coordinator reran 52/52 on `main`). The conditions are binding on M03.03.01+ and listed in `docs/spikes/rushdb-validation.md` §9. (1) Only the API/workers hold `RUSHDB_TOKEN`; the tenant scope is derived server-side from an org validated in PostgreSQL, because unknown scopes auto-register empty tenants. (2) A single adapter injects the workspace and published-revision predicate on every query block, and never uses `query.text`, `query.record` or user statements. (3) Image pinned to 3.0.10; spikes rerun on every upgrade. (4) Backups use cold volume snapshots, and the restore smoke test checks BM25. (5) M04 benchmarks realistic dimensions and volumes. **Residual risk the user should know:** the engine shipped 3.0.0 on 2026-10-29, eleven releases in about two weeks, and `deleteRecords`/`purgeTenant` are not transactional. The ADR stays unchanged, so no approval is required, but this is the decision most worth revisiting if RushDB churns. | Applied |

| DC-011 | 2026-11-16 | User decision | **Local inference runtime: LM Studio (`lms`) instead of Ollama**, at the user's direction. LM Studio runs natively on the Windows host, so it gets direct GPU access, and serves an OpenAI-compatible API on `127.0.0.1:1234`. Containers reach it at `host.docker.internal:1234` (verified HTTP 200 from a container). Consequences: (1) no inference container in compose; the AI runtime is a host prerequisite in the runbook. (2) The model gateway (M04.02.01) and embedding adapter (M03.02.05) target the OpenAI-compatible `/v1` API, so Ollama, llama.cpp `llama-server` or vLLM stay drop-in alternatives (ADR-020/022 unchanged). (3) LM Studio is free to use but **closed-source**; the licence terms are recorded in `docs/spikes/local-models.md`. (4) The partial Ollama benchmark was stopped, and its numbers are not used. Volume `ukos-models_ollama-models` (6 models, 12.64 GB) was deleted at the user's request on 2026-11-16, along with its stopped container and network. | Applied |
