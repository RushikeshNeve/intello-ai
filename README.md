# Universal Knowledge OS

A local-first, multi-tenant AI knowledge management system: Next.js + FastAPI modular monolith, PostgreSQL
(authoritative), RushDB 3 (knowledge index), S3-compatible object storage, Redis/Celery, local inference.
$0 recurring hosting.
